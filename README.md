# Nyota Herbal & Natural Wellness — Hyper Marketplace

Feature-enhanced React + TypeScript + Vite marketplace with Supabase authentication/database/storage, seller-specific product contacts, super-admin product inquiries, basket/checkout, order and payment tracking, admin account management, WhatsApp Business alerts, optional M-Pesa Daraja STK Push/callback, and automatic device-theme synchronization.

Start with [SETUP.md](./SETUP.md). Apply `supabase/schema.sql` first, then `supabase/commerce-enhancement.sql`. Configure the required Supabase secrets and deploy the Edge Functions before enabling account-management, WhatsApp or M-Pesa flows.
